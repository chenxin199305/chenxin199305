- 🏢 **R&D Director** @ [Fourier Intelligence (FFTAI)](https://github.com/FFTAI) — leading the robot control system team
- 🦿 Building **GRx series humanoid robots** (N1 / M4 / HXC) — deployment, SDK, sim-to-real RL
